# Operations_KPI_Excel_Project

## 📌 Project Overview
This project demonstrates how to identify and handle missing data in Excel using practical techniques commonly used in data analysis.

## 🛠 Tools Used
- Microsoft Excel

## 📊 Techniques Covered
- Identifying missing values
- Handling missing numerical data using mean and median
- Handling missing categorical data using "Unknown"
- Using Excel formulas like IF, ISBLANK, AVERAGE, MEDIAN

## 🎯 Key Learnings
- Importance of handling missing data before analysis
- Impact of missing values on data accuracy
- Practical Excel skills for entry-level data analyst roles
